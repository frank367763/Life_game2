# Game of Life

Одна из моих ранних учебных работ на C++ — клеточный автомат «Жизнь» с выводом через SDL2.

Поле хранится в классе `LifeGrid`: текущее и следующее поколения находятся в отдельных векторах. На каждом шаге для клетки подсчитываются восемь соседей. Живая клетка остаётся живой при двух или трёх соседях; пустая оживает при трёх. За границами поля живых клеток нет.

## Управление

При запуске в консоли можно выбрать `r` для случайного заполнения или `m` для расстановки клеток мышью. Enter запускает симуляцию, закрытие окна завершает программу. Класс `G` в [screen.h](screen.h) отвечает за окно и отрисовку.

## Сборка и состояние

Для сборки нужны компилятор C++ и библиотека SDL2 с заголовками и файлами для линковки. Готовой конфигурации CMake и исполняемого файла здесь пока нет; сборка на чистой машине не проверена.

Это сохранённая учебная версия. В ней ещё есть несоответствие масштаба координат мыши и отображения, а русские строки в исходнике требуют исправления кодировки. Код оставлен как пример более ранней работы; более свежие приложения — [Nexus Studio](https://github.com/frank367763/nexus-studio) и [ArrayLab](https://github.com/frank367763/array-lab).
